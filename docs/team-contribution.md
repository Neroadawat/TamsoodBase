# หลักฐานการมีส่วนร่วมของทีม

ยังไม่มีรายชื่อ/บทบาท/ผลตรวจจากสมาชิกที่ยืนยัน จึงไม่ใส่ชื่อและไม่สร้างหลักฐานแทนมนุษย์ สมาชิกเพิ่มเฉพาะงานที่ทำจริงพร้อม artifact และวันเวลา

| สมาชิก | วันเวลา | งานที่ทำจริง | ไฟล์/issue/commit/ผลตรวจ | ผู้ทบทวน | สิ่งที่อธิบายได้/ปัญหาที่พบ |
|---|---|---|---|---|---|
| รอสมาชิกกรอก | | | | | |

หลักฐานอาจเป็น source review ที่บันทึกตำแหน่งตัวเลข, mapping decision, SQL ที่รันพร้อมผล, code review หรือ demo rehearsal ไม่ใช้จำนวน commit อย่างเดียวแทนคุณภาพการมีส่วนร่วม

## งาน AI-assisted ที่ต้องเปิดเผย

ผู้ช่วยช่วยเตรียม acquisition/processing/review scripts, MySQL/SQLite schema, API/Explorer, reference policy, automated PDF trace, export/package, tests, SQL benchmark และเอกสารใน repo นี้ การตรวจอัตโนมัติใช้ actor AUTOMATED_TEAM_POLICY_V1 สมาชิกต้องอ่าน ตรวจ และรับผิดชอบส่วนที่ตนนำไปใช้ตามนโยบายรายวิชา

หากสร้าง Git history ภายหลัง ให้เริ่มจากเวลาที่ทำจริง ห้ามสร้าง commit ย้อนหลังหรือปลอม author เพื่อแสดงว่าสมาชิกมีส่วนร่วม
