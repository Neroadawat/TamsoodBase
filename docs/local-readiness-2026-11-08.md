## ผลค้นจากคำถามใหม่

ไฟล์ `docs/rag/evaluation-questions.json` กำหนดคำถามและผลคาดหวังก่อนรัน: 12 คำถามในขอบเขต, 8 คำถามที่ไม่มีคำตอบใน corpus และ 4 คำถามกำกวม เขียนโดยผู้ช่วยรอบนี้ ไม่ใช่การประเมินอิสระโดยสมาชิกหรือ user study

- คำถามในขอบเขตได้การ์ดถูกอันดับแรกและผ่าน cutoff **11/12**
- คำถามไม่มีคำตอบไม่คืนการ์ด **7/8**
- คำถามกำกวม 3 ข้อไม่คืนการ์ด; คำว่า “คาร์บอน” คืนการ์ดช่องว่างเอทานอล ไม่ให้คะแนนถูก/ผิดเพราะเจตนายังไม่ชัด
- ทุกการ์ดมี source URL และ locator; ตรวจ HTTP ว่าข้อความ/ที่มาที่ส่งกลับตรง corpus แต่ไม่ได้ตรวจบทความต้นฉบับใหม่หรือรับรองว่า URL ทุกแห่งยังเปิดได้

ข้อผิดพลาดที่ต้องคงบันทึก:

1. “งาน Songkitti รายงานการกินน้ำมันช่วง cold start ไว้อย่างไร” ไม่พบการ์ดที่ผ่าน cutoff; ชื่อผู้แต่งและภาษาอังกฤษผสมไทยยังค้นได้ไม่ดี
2. “รถ E20 วิ่งทางไกลมีค่า N2O กี่กรัมต่อกิโลเมตร” คืน E10 cold-start ที่คะแนน 0.668543 ทั้งที่หลักฐานตอบไม่ได้ นี่เป็นความผิดพลาดด้านความเพียงพอของหลักฐาน ไม่ใช่แค่การจัดอันดับ

ทดลอง cutoff 0.35/0.45/0.55/0.65/0.70/0.75 จากคะแนนชุดเดียวกัน: ที่ 0.70 ปฏิเสธคำถามไม่มีคำตอบครบ 8/8 แต่เหลือคำถามในขอบเขตผ่านเพียง 5/12 จึงคงค่าเดิม 0.45 และบันทึกว่า **ยังไม่พร้อมใช้เป็นระบบรับรองคำตอบ** ไม่ปรับเพื่อให้คะแนนชุดนี้ดูดีขึ้น

ปรับหน้าค้นให้ระบุว่ามีเพียง 4 การ์ด ผลค้นอาจเกี่ยวข้องแค่บางส่วน และห้ามใช้ค่า E10 ยืนยัน E20/N₂O ยังไม่มีตัวตรวจความเพียงพอทางความหมายอัตโนมัติ การปรับข้อความไม่ได้แก้ false positive ของ retrieval

## เปิดใช้งานและตรวจซ้ำ

ใช้วิธีเปิด/เตรียมเครื่องใน [คู่มือรับช่วงปัจจุบัน](TEAMMATE_NEXT_STEPS_TH.md) และวิธีประเมินโค้ดปัจจุบันโดยเก็บผลแยกรอบใน [RAG README](rag/README.md) ต้องหยุด RAG ก่อนประเมินเพราะ Qdrant Local เปิดได้ทีละ process และระบุ `--output` ใหม่ใต้ `build/handoff/rechecks/` ไม่เขียนทับไฟล์ประวัติใน `evidence/`

ผลจากโค้ด/corpus ปัจจุบันไม่ใช่การ replay ผล 4 การ์ดในรายงานนี้ ตัวตรวจ HTTP ปัจจุบันเขียนผล 10 การ์ดลง `evidence/rag-expanded-http-2026-11-08.json`; หากต้องเก็บผลเครื่องผู้ส่งเดิมให้ใช้ checkout แยก

เครื่องใหม่ให้ติดตั้ง/index ตาม `docs/rag/README.md` ก่อน environment และ model cache ไม่ตาม Git; เก็บ dependency versions ทั้งหมดของรอบนี้ใน `build/rag/requirements-resolved.txt` โมเดล ONNX SHA256 `634d0f66c29dc934c8fa72b8a4fe91dd4d420a22f1d82a241058d4316e659a99` ส่วน corpus/question hashes และผลรายข้ออยู่ใน evidence

## ข้อค้าง ณ รอบแรก

รายการด้านล่างเป็นประวัติ ให้ใช้รายการที่ยังเปิดในคู่มือรับช่วงปัจจุบันตัดสินงานต่อ

1. หากต้องเปิดข้อมูลวิจัยเต็ม ต้องรับ snapshot/manifest ที่ถูกสิทธิจากเจ้าของ หรือเลือก acquire เฉพาะแหล่งตามคู่มือ แล้วตรวจ hash ก่อน replay; Docker engine ต้องพร้อมก่อนตรวจฐานทดลอง
2. ก่อนเพิ่ม Gemini ให้แยก “พบข้อความคล้าย” ออกจาก “มีหลักฐานตอบจริง” โดยเฉพาะชนิดเชื้อเพลิง สาร หน่วย และขอบเขต; เพิ่มคำถามจากสมาชิกจริงและชุดทดสอบใหม่ที่ไม่ได้ใช้ปรับระบบ
3. ขยายการ์ดเฉพาะข้อมูลที่ตรวจที่มา/สิทธิแล้ว และประเมินใหม่ ไม่อ้างผล 4 การ์ดแทนข้อมูลทั้งโปรเจกต์

หลักฐาน: `evidence/rag-local-evaluation-2026-11-08.json`, `evidence/rag-local-http-2026-11-08.json` ผลครั้งนี้ไม่ใช่การรับรอง LCI หรือ final submission
