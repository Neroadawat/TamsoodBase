## Validation และข้อจำกัด

- ค่าต้อง finite และไม่ติดลบสำหรับชุดนำร่องนี้; ศูนย์ไม่ใช่ missing และไม่ใช่เหตุ reject
- ต้องมีเวลา พื้นที่ หน่วย และ locator; period ต้องตรง evidence
- ป้องกันรายการซ้ำภายใน batch ตาม period/area/block/field/fuel/unit และ record_id
- ยังไม่รองรับ dedup ข้าม publisher, revision หรือการรวมรายเดือนกับรายปี
- รายการที่ไม่ผ่านอยู่ใน rejected_record พร้อมเหตุผล ไม่ถูกลบทิ้งเงียบ ๆ
- technical PASS หมายถึงผ่านกฎรูปแบบเท่านั้น ไม่ยืนยัน numerical accuracy หรือ LCI eligibility
- ไม่มีการเปลี่ยนเป็น accepted อัตโนมัติ; review_status ถูกจำกัดไว้ที่ PENDING
- ชุดนี้ไม่รวมยอดรวม ไม่เพิ่มจำนวนจากคอลัมน์หน่วยเทียบเท่า

ก๊าซที่ผลิตตามนิยาม DMF รวมขาย ใช้เป็นเชื้อเพลิงในพื้นที่ และเผาทิ้ง จึงเทียบกับยอดขายโดยตรงไม่ได้
ต้องตรวจ reference conditions ของปริมาตรก๊าซก่อนเปรียบเทียบหรือแปลงหน่วย

## โครงสร้างทดลอง

source 1:N batch; batch 1:N observation; unit 1:N observation
rejected_record เก็บแถวที่ไม่ผ่านใน run นี้ เอกสาร JSON เก็บ metadata แหล่งข้อมูล
ก่อนขยายต้องออกแบบ source revision, evidence artifact, process/flow/location และ human review ให้ครบจากแหล่งจริงและกติกาที่อนุมัติ
