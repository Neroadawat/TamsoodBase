# ให้สมาชิกลองค้นและตรวจหลักฐานจริง

เปิด `http://127.0.0.1:8767/` หลังรันบริการตามคู่มือรับช่วงงานล่าสุด

1. เขียนคำถามที่ต้องใช้กับโครงงานจริง 3–5 ข้อก่อนกดตัวอย่างบนหน้าเว็บ
2. ค้นแล้วเปิดที่มา ตรวจชนิดเชื้อเพลิง สาร หน่วย ฐานคำนวณ และช่วงทดสอบว่าตอบคำถามได้จริงหรือเพียงคล้ายกัน
3. เลือก “มีหลักฐานเพียงพอ”, “หลักฐานยังไม่พอหรือผิดขอบเขต” หรือ “ยังไม่แน่ใจ” พร้อมข้อสังเกตถ้ามี แล้วกดบันทึก
4. หากไม่มีผลค้น ให้ประเมินด้วยว่าเป็นเรื่องที่ควรมีข้อมูลหรือเป็นเรื่องนอกขอบเขต ระบบรับผลประเมินกรณีนี้ได้เช่นกัน

คำถามและผลประเมินเก็บใน `.local/rag-feedback.jsonl` ซึ่งไม่เข้า Git ไม่ต้องใส่ชื่อ คีย์ หรือข้อมูลส่วนตัว ข้อคิดเห็นจะผูกกับผลค้นและรุ่นการ์ดที่แสดงจริง บันทึกซ้ำจากผลค้นเดียวกันไม่ได้

แบบประเมินไม่ยืนยันตัวตน จึงไม่ใช่หลักฐานรับรองจากทีมโดยอัตโนมัติ ต้องให้สมาชิกทบทวนผลจริงก่อนสรุป user study หรือการรับรองงาน ผู้ช่วยไม่กรอกผลแทนสมาชิก การทดสอบระบบบันทึกอัตโนมัติใช้ไฟล์ชั่วคราวแยกจากผลจริง
