# ฐานอ้างอิงและขอบเขตของ Inventory

## ผลตรวจที่แก้ความเข้าใจเดิม

บทความ DOI10.3390/su12229415 ระบุใน Section2.1 ว่า Functional Unit คือ **การใช้เชื้อเพลิง1000MJ** ขอบเขตงานวิจัยเริ่มจากการปลูก/เก็บเกี่ยวปาล์ม การผลิตและกลั่นน้ำมันปาล์ม ขนส่ง ผลิตเชื้อเพลิง จนใช้ในรถกระบะ จึงไม่ควรบอกว่าแหล่งนี้ไม่มีFU

อย่างไรก็ตาม ข้อมูลที่TamsoodBaseนำเข้าคือ **16ค่าจากTable4ของขั้นแปรรูปFAME/H-FAME** ไม่ใช่ทุกกระบวนการของการศึกษานั้น ระบบจึงมีFUของแหล่งที่อ้างอิงได้ แต่ยังไม่มีLCIที่เชื่อมครบขอบเขตทั้งวงจร และไม่กำหนดFUนี้ครอบDMF/NSO/EPPO/รายงานองค์กร

## สัญญาข้อมูลที่เพิ่ม

`src/inventory_scope.py` ตรวจทีละprocess:

- observation_idไม่ว่างและไม่ซ้ำ
- reference_amountเป็นข้อความDecimalที่finiteและมากกว่า0; reference_unitไม่ว่าง
- ทุกexchangeในprocessต้องใช้ฐาน ขอบเขต พื้นที่ เทคโนโลยี ปีเผยแพร่ ช่วงปีวัด allocation DOIและsnapshotเดียวกัน
- มีREFERENCE_PRODUCTหนึ่งรายการ เป็นOUTPUT และปริมาณมากกว่า0
- role/directionต้องเข้ากัน;ค่าปริมาณfiniteไม่ติดลบ
- ไม่รับการอ้างis_full_lci_dataset=trueผ่านสัญญาforegroundนี้

ตัวvalidatorถูกเรียกก่อนรับผลextractจาก`build_product_inventory.py`;รายงานที่สร้างใหม่จะมีstructuredscopeแยกstudyfunctionalunit/importedboundary/processreferencebasis/referenceproduct/openissues ไม่คูณallocationหรือเปลี่ยนตัวเลขเดิม

โครงสร้างนี้เป็นmetadataจากข้อมูลที่เก็บแล้ว ไม่ใช่การmigrateSQLใหม่หรือการแก้ข้อมูลMySQLบนEC2 ตัวAPIproductionเดิมยังมีpayloadเดิม แต่ตรวจข้อมูล16รายการของAPIจริงผ่านvalidatorใหม่ครบแล้ว หน้าเว็บเพิ่มFUและขอบเขตด้วยข้อมูลต้นทางที่ตรวจนี้ และปฏิเสธการแสดงกลุ่มที่contextไม่สอดคล้องกัน

## สิ่งที่ยังขาดก่อนขยายทั้งวงจร

1. Unitprocessและexchangesของการเพาะปลูก โรงสกัด/กลั่นปาล์ม ขนส่ง การผลิตไฟฟ้า/สารเคมี และการใช้ในรถ ที่เชื่อมกับreferenceflowsได้จริง
2. ปี/พื้นที่/เทคโนโลยีและแบบจำลองbackgroundที่เข้ากัน พร้อมสิทธิใช้ข้อมูล
3. หลักฐานว่าตารางที่เลือกใช้allocationมาแล้วขั้นไหน เพื่อไม่คูณ70%ซ้ำ
4. การจับคู่elementaryflows/compartmentsและการตรวจความครบถ้วนของขอบเขต

ไม่มีค่าช่องว่างใดถูกแทนเป็น0 ไม่มีการอ้างว่าข้อมูลโรงงานบางแห่งหรือpilotplantเป็นค่าเฉลี่ยประเทศไทย และไม่ใช้impactscoreCO2eแทนรายการสารที่ปล่อย

## หลักฐานและการทำซ้ำ
