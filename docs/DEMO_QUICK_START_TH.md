# เดโม TamsoodBase แบบสั้น

**ฉบับล่าสุดหลังผู้ใช้ขอแก้ UX ใหม่:** แถบเส้นทางเดโมและโหมดนำเสนอด้านล่างถูกนำออกแล้ว ให้เปิดหน้าแรก เลือกหัวข้อหนึ่งใน5ใบ → ดูข้อมูล → ดูที่มา เว็บไซต์ต้นทางและCSVยังอยู่คู่กัน แถวCSVแบบเต็มกดขยายได้ ตัวเลขDMFอยู่เฉพาะหน้าการผลิต/คุณภาพ ไม่แสดงทุกหน้า รายละเอียดด้านล่างเป็นประวัติT79 ไม่ใช่คำแนะนำรุ่นปัจจุบัน ดูevidence/catalog-simplification.json

เปิด https://tamsoodbase.vercel.app/#nso แล้วคลิก **เส้นทางเดโม** ด้านบน เลือก **โหมดนำเสนอ** เพื่อซ่อนภาพรวมและเห็นตารางมากขึ้น ปิดได้ทุกเมื่อ ไม่เปลี่ยนข้อมูลหรือล้างตัวกรอง

1. **ตัวเลขระดับประเทศ**: กด “ลองตัวอย่าง: ดีเซล ปี 2024” แล้วเลือก “หลักฐาน” ของค่าหนึ่งรายการ อธิบายค่า หน่วย ปี และความต่างระหว่าง production/consumption
2. **ตามกลับต้นทาง**: ในหน้าหลักฐาน เลือก “เว็บไซต์รายงาน สสช.” เพื่อดูบริบทรายงาน หรือเลือก “ไฟล์ CSV ที่ใช้สกัดข้อมูล” เพื่อเปิดไฟล์จริง ทั้งสองเปิดแท็บใหม่ กลับแท็บเดิมเพื่อเห็นบรรทัด/คอลัมน์และช่องที่เน้นสี
3. **ค่าที่บริษัทรายงาน**: เลือกขั้น2 แล้วเปิดรายการหนึ่ง ชี้ปี/ขอบเขต/หน้าPDF บอกว่า ACCEPTED_REFERENCE ไม่ใช่ค่าต่อผลิตภัณฑ์หรือใบอนุญาตแจกจ่าย
4. **Inventory ต่อฐานอ้างอิง**: เลือกขั้น3 แล้วอ่านฐาน1000MJและboundaryก่อนเปิดTable4ของงานวิจัย ไม่รวมข้อมูลทั้งห้าชั้นเป็นจำนวนLCIเดียว
5. **เหตุผลที่พักและที่มา**: เลือกขั้น4/5 ชี้ตัวอย่างHOLDและSourceID อย่าพูดว่าเลขทุกต้นทางถูกต้องทั้งหมดหรือเป็นการวัดอิสระ

เว็บไซต์เจ้าของอาจเปลี่ยนไฟล์หลังวันเก็บ ข้อมูลในระบบผูกกับsnapshot/hashเดิม หน้าเว็บไซต์ช่วยอ่านบริบท แต่CSVเป็นหลักฐานไฟล์ที่สกัดจริง การเพิ่มลิงก์เว็บไซต์ไม่ใช่การตรวจยืนยันตัวเลขเพิ่ม

## ตรวจรอบนี้

- ทดสอบ128testsผ่าน รวมการคงค่า0/ช่องว่าง การเน้นคอลัมน์source1-based ลิงก์HTTPSที่ไม่ฝังcredentials ตัวกรองตัวอย่าง และโหมดนำเสนอ
- Buildfrontendมีเฉพาะpublicassets ไม่มีrawPDF/CSV/ฐานข้อมูล/secret
- ProductionHTML/JS/CSSเทียบhashกับbuildแล้ว;API27routesตรงbaseline รวมการปฏิเสธfilterเสีย และexportไม่ถามlogin
- เครื่องมือควบคุมbrowserเริ่มต้นไม่ได้ จึงยังไม่มีผลvisual/interactionจากbrowserจริงของรุ่นนี้ การทดสอบพฤติกรรมเป็นDOMจำลองและHTTP ไม่ใช่userstudy
- ข้อมูล/backend/สิทธิไม่ได้เปลี่ยน;ผลcross-publication169/273ในrepositoryยังไม่ถูกย้ายไปAPIproductionจากงานปรับUIนี้
