## เหตุผลที่ยังไม่เชื่อมเข้ากรณี FAME ของทีม

ผู้ให้ข้อมูล CPO ในกรณีปัจจุบันไม่ได้จับคู่กับกลุ่มโรงงานในลุ่มน้ำ Tapi และคนละช่วง/โครงสร้างสถานการณ์ อีกทั้งยังไม่มี CH4 ที่ปล่อยจริงหรือยอด CPO จริงของโรงงานเดียวกันในงวดเดียวกัน จึงยังปิดช่องว่าง methane-plus-output ไม่ได้. ค่า Table 2 ไม่ได้ถูกนำเข้า `evidence/lifecycle-candidate.json`; ไม่คำนวณ CO2e เพิ่ม ไม่เปลี่ยน allocation และ `CO2e_total` คงเดิม.

หน้า PDF ของผู้พิมพ์ถูกระบบป้องกันอัตโนมัติขวางการดาวน์โหลดในรอบนี้ จึงตรวจเนื้อหาจาก full-text extraction ที่เว็บให้มา แต่ **ยังไม่ได้ตรวจภาพตาราง/ทุกเซลล์, ทำ local PDF hash, หรือยืนยันใบอนุญาตแจกจ่าย**. เพื่อไม่ยกระดับหลักฐานเกินจริง จัดเป็น `HOLD_CONTEXT`, `redistribution_status=NOT_CLEARED`, ไม่เผยแพร่ในเว็บ/RAG และไม่คัดลอกตารางตัวเลขลง public corpus. หลักฐานเครื่อง: [`evidence/scientific-source-check-2026-11-10.json`](../evidence/scientific-source-check-2026-11-10.json).

## หลักฐานที่ยังต้องหาเพื่อปิดช่อง

1. มวล CH4 ที่วัด/กู้คืน/รั่วจริง พร้อมขอบเขตและงวดเวลา.
2. ยอด CPO จริงของโรงงานเดียวกันในงวดเดียวกัน.
3. หลักฐานเชื่อมตัวตนโรงงานและวิธีบำบัด POME/EFB เข้ากับ provider ใน chain ปัจจุบัน.
4. ฐานก่อน/หลัง allocation ของตาราง FAME ปัจจุบัน.
5. ตรวจภาพ/ช่องตารางและสิทธิใช้ก่อนพิจารณา import หรือเผยแพร่.
