## กฎตัดสินที่ใช้

Identity ชั่วคราว: package + ปี + เดือน + ประเภทพื้นที่ + block label + source group
ข้อมูลในกลุ่มเดียวกันต้องเหมือนกันทุกช่องต้นทางจึงรวมสำเนาได้
ไม่ได้ตัดสินจาก amount อย่างเดียว และไม่ได้ใช้วันที่/ลำดับแถวเพื่อเลือกค่าขัดกัน
ตัวแทนบรรทัดต่ำสุดเป็นตัวแทนสำเนาภายใน snapshot ไม่ใช่ revision ล่าสุดหรือแหล่งที่เชื่อถือได้มากกว่า
ถ้าค่าตัวเลขเท่ากันแต่จำนวนวันที่ผลิตหรือค่าเทียบเท่าต่างกัน กลุ่มนั้นยังถูกพัก
ถ้า identity ไม่พอแยก observation จริง กลุ่มอาจไม่ใช่ duplicate — ต้องตรวจรายงานก่อนสรุป

## ผลตรวจหน่วยและตัวเลข

อ่านรายงาน DMF มกราคม 2569 ผ่านข้อความจากเครื่องมือเว็บ:
https://dmf.go.th/public/createpetroleum/data/report/menu/1114/year/2569/month/1

รายงานระบุ GAS เป็นล้านลูกบาศก์ฟุต/วัน และ CONDENSATE/OIL เป็นบาร์เรล/วัน
เทียบ 4 ชื่อแหล่ง × 3 ผลิตภัณฑ์ = 12 ค่า โดยค่า CSV ต้องต่างจากค่ารายงานน้อยกว่า 0.005 ตามความละเอียดแสดงสองตำแหน่ง
ทั้ง 12 ค่าตรงภายในความละเอียดนั้น แต่ตรวจพบชื่อแปลงตรงกันแบบ exact เพียง 7 ค่า:

- ไพลิน / มรกต: รายงานระบุ `B12/27 G7/50` แต่ CSV ทั้งสามชุดเป็น `B12/27`
- อาทิตย์: รายงานเป็น `14A-16A`; CSV condensate ตรงกัน ขณะที่ oil/gas เป็น `14A16A`
- จัสมิน บานเย็น และน้ำพอง: block label ตรงกันทั้งสามผลิตภัณฑ์

ห้ามเปลี่ยนชื่อแปลงอัตโนมัติเพื่อทำให้ match; ชื่อกลุ่มอาจสะท้อน scope/revision ต่างกัน
ตัวอย่างมีการเลือกเองและบางค่าเป็นศูนย์ จึงไม่ใช้คำนวณอัตราความถูกต้องทั้ง dataset
นี่เป็นการตรวจข้ามรูปแบบภายใน publisher เดียว ไม่ใช่ independent source verification

หลักฐานตัวอย่างอยู่ `evidence/dmf-report-2026-01-sample.json` ระบุว่าเป็น manual transcription ของ web text ไม่ใช่ raw HTML/PDF snapshot
ค่า SHA256 ของ artifact นี้พิสูจน์ว่าใช้บันทึกฉบับใด ไม่ใช่การรับรองว่าเป็นไฟล์ต้นฉบับจาก DMF
ลองเปิดรายงานมีนาคม 2551 และมีนาคม 2569 ผ่านเครื่องมือเว็บเพิ่มเติมแล้วไม่สำเร็จ จึงยังไม่มีหลักฐานให้ใช้ตัดสินคู่ค่าขัดกันในอดีต

ข้อสรุป: มีหลักฐานสนับสนุนว่า selected CSV cells มกราคม 2569 สัมพันธ์กับรายงานอัตราต่อวัน แต่ยังไม่ยืนยันฐานเวลาของ CSV ตลอด 2003–2026
ยังไม่กำหนด canonical unit ให้ทั้งชุด และไม่คูณ DAYSOFPRODUCE เพื่อสร้างปริมาณรายเดือน

## วิธี reproduce

```powershell
python -X utf8 src/process_dmf.py
python -X utf8 src/review_dmf.py
python -m unittest discover -s tests -v
```

ผลใน `build/dmf/<run_id>/`:

- `duplicate-disposition.csv`: ทุกแถวในกลุ่มซ้ำ พร้อม representative/hold และ raw_json
- `deduplicated-candidates.csv`: ชุดรอตรวจที่ไม่ซ้ำและไม่อยู่ในกลุ่มขัดกัน
- `review-report.json`: ผลตรวจตัวเลขทุกค่าและผลบริบทแปลง
- `candidates.sqlite`: view deduplicated_candidates และ duplicate_disposition สำหรับ query

raw snapshot ถูกเก็บ local และ gitignore ระหว่างตรวจเงื่อนไขเผยแพร่ซ้ำ
