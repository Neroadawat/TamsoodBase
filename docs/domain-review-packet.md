# ชุดตัวอย่างเพื่อยืนยันขอบเขตการแข่งขัน

สถานะ: เตรียมสำหรับทีมใช้สอบถามผู้สอน/MTEC ยังไม่ได้ส่ง และยังไม่มีคำอนุมัติ ห้ามเปลี่ยนสถานะเป็น accepted จากเอกสารนี้

## คำถามที่ต้องยืนยันครั้งเดียวก่อนขยายจำนวน

โครงการยอมรับข้อมูลระดับใดเป็น Accepted Tuple: สถิติการผลิต, annual input/output ระดับองค์กร, reported intensity ต่อ throughput หรือจำเป็นต้องเป็น inventory exchange ที่มี process และ reference product ชัดเจน? สำหรับแต่ละชนิด ต้องมี field และหลักฐานขั้นต่ำอะไรบ้าง?

## ตัวอย่าง 3 ประเภทจากระบบจริง

| ตัวอย่าง | ข้อมูลที่มี | สิ่งที่ยังไม่ทราบ | ประเด็นขอวินิจฉัย |
|---|---|---|---|
| DMF: การผลิตก๊าซตามแหล่งและเดือน | ประเทศไทย ผลิตภัณฑ์ กลุ่มแหล่ง เดือน ค่า หน่วย metadata ตัวคูณ และตำแหน่ง CSV | ฐานเวลาของค่าปริมาณย้อนหลังและ process reference basis | นับเป็น LCI tuple ได้หรือเป็น contextual statistics เท่านั้น? |
| ไทยออยล์: ก๊าซธรรมชาติที่ใช้ ปี 2021 | 33.32 Million GJ; PDF หน้าไฟล์ 60/เลขพิมพ์ 63; เชิงอรรถครอบคลุม TOP/TPX/TLB/LABIX/TOPSPP | การจัดสรรให้ผลิตภัณฑ์และขอบเขต process เดี่ยว | annual organizational input นับได้หรือไม่ ต้องแยกหน่วยผลิตอย่างไร? |
| SPRC: fuel intensity ปี 2024 | 2.57 GJ/t throughput; PDF หน้าไฟล์ 121/เลขพิมพ์ 120 | ตัวหารเชิงนิยาม ขอบเขตเฉพาะโรงกลั่น และการจัดสรรผลิตภัณฑ์ | reported intensity นับได้หรือไม่ ต้องมี input/output ครบ process หรือไม่? |

ตัวเลขสองรายงานเป็น transcription/extraction จากเอกสาร ไม่ได้ normalize หรือสร้างค่าทดแทน รายการ DMF ให้เปิดตัวอย่างจริงใน Explorer เพื่อเลือก source line พร้อม snapshot ของรอบที่ใช้

## คำถามประกอบด้านกติกา

1. มี canonical schema และ mandatory fields ล่าสุดหรือไม่?
2. ข้อมูลซ้ำต่างแหล่งและต่าง version ให้นับอย่างไร? ตาราง total กับ components แยกนับได้ภายใต้เงื่อนไขใด?
3. numerical verification ต้องตรวจทั้งหมดหรืออนุญาต sampling แบบใด และ evidence แบบใดใช้ได้?
4. สิทธิการใช้รายงานบริษัทสาธารณะต้องมีใบอนุญาตระดับใด และส่ง raw/evidence ภายในชั้นเรียนได้อย่างไร?
5. วันส่ง DBMS รูปแบบไฟล์ และนโยบาย AI ฉบับล่าสุดคืออะไร?

เมื่อมีคำตอบ ให้เก็บต้นฉบับคำตอบ วันที่ ผู้ประกาศ และเวอร์ชันเป็น rule evidence ก่อนแก้ business rules ห้ามบันทึกคำตอบที่อนุมานเองว่าเป็นคำตอบจาก MTEC
