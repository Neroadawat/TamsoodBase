# ส่วนที่เจ้าของและสมาชิกต้องเติมจริง

ยังไม่กรอกชื่อ รหัสนักศึกษา ลายเซ็น ผลซ้อม หรือประวัติการมีส่วนร่วมแทนใคร

- [ ] ชื่อโครงงาน รายชื่อ/รหัสสมาชิก section และหัวหน้าทีมตามจริง
- [ ] cover sheet/รูปแบบไฟล์/ข้อกำหนดรับรองตามAssignmentล่าสุด ถ้ามี
- [ ] deadline/ช่องทาง/ชื่อไฟล์/ขนาดไฟล์ล่าสุด ตรวจจากTeams ไม่อนุมานจากW15
- [ ] contributionแต่ละคนพร้อมartifact/วันเวลา/ผู้reviewและสิ่งที่อธิบายได้
- [ ] peerassessment/reflectionตามกิจกรรมที่เกิดจริง
- [ ] เปิดsourceหนึ่งacceptedและหนึ่งhold แล้วอธิบายปี/หน่วย/scope/locatorได้
- [ ] รันSQLตามusecaseและอธิบายJOIN/PK/FK/constraintsได้
- [ ] ตรวจAI-assistedงานที่นำไปใช้ เปิดเผยและรับผิดชอบตามassessmentpolicy
- [ ] reviewสิทธิของไฟล์ที่จะส่ง ไม่แนบraw/PEM/.local/secretsโดยเผลอ
- [ ] ตรวจzipmanifest/hashและไฟล์ที่อาจารย์กำหนดเพิ่มเติมก่อนfreeze
- [ ] ส่งด้วยบัญชีเจ้าของ ตรวจTurned inและเก็บหลักฐานส่งจริง

ไม่ถือว่าช่องเหล่านี้ถูกติ๊กแล้วเพียงเพราะมีเอกสารนี้ หรือเพราะตัวตรวจเทคนิคผ่าน
