# นโยบายคัดข้อมูลของทีม v1

การตัดสินใจ 22 ตุลาคม 2569: ผู้ใช้ให้ทีมกำหนดความเหมาะสมและทำข้อมูลให้ใช้ต่อได้จริง ไม่ต้องรอคำยืนยัน MTEC การอนุมัติระดับทีมตามนโยบายนี้ไม่ใช่คำรับรองจาก MTEC และไม่รอคำรับรองนั้นเป็น dependency

## ผลิตภัณฑ์ข้อมูลที่ส่งมอบ

สร้างฐานข้อมูลอ้างอิงด้านปิโตรเลียมและเชื้อเพลิงของประเทศไทย เก็บข้อเท็จจริงตามระดับรายละเอียดที่แหล่งรายงานจริง ใช้ค้น ตรวจย้อนกลับ และเป็น input ประกอบการทำ inventory ได้ โดยไม่สร้าง process/reference product หรือค่าเฉลี่ยประเทศขึ้นเอง

| ชนิดข้อมูล | ใช้ทำอะไรได้ | สิ่งที่ข้อมูลยังไม่รองรับ |
|---|---|---|
| ORGANIZATION_INPUT | ค้นการใช้พลังงาน/ทรัพยากรรายปีภายในขอบเขตองค์กรที่ระบุ | ไม่ถือเป็นค่าใช้ต่อผลิตภัณฑ์โดยอัตโนมัติ |
| ORGANIZATION_OUTPUT | ค้นไฟฟ้าที่ขายหรือน้ำเสียที่รายงาน โดยอ่านนิยามประกอบ | ไม่ถือเป็น elementary emission หรือผลกระทบสิ่งแวดล้อมทั้งหมด |
| REPORTED_INTENSITY | ใช้ค่า intensity ที่รายงานพร้อมตัวหารเดิม | ไม่เปลี่ยน throughput เป็น reference product หรือใช้ย้อนหาปริมาณจริงจากค่าปัดเศษ |
| CONTEXT_METRIC | ประกอบความเข้าใจ เช่น throughput และ net water consumption | ไม่บวกเป็น flow เพิ่มใน inventory |
| PRODUCTION_STATISTIC | ค้น production context เช่น DMF แยกเป็นอีกชุดข้อมูล | ฐานเวลาที่ไม่ยืนยันห้ามนำไปคำนวณยอดรายเดือน/ปี |

## การรับข้อมูลเข้าชุดอ้างอิง

สถานะ ACCEPTED_REFERENCE หมายถึงทีมยอมรับเป็นข้อเท็จจริงจากเอกสารที่อ้างอิงได้สำหรับการศึกษาภายในภายใต้ profile LOCAL_RESEARCH_REFERENCE ต้องมีค่า หน่วย ปี ขอบเขตตามที่รายงาน source hash/page/column, ผ่านการสกัดซ้ำทุกค่าของ subset ที่เลือก และไม่มี issue ด้านบริบทที่ยังเปิดอยู่

HOLD_CONTEXT หมายถึงคงข้อมูลไว้เพื่อทบทวนแต่ไม่นำเข้า default reusable export ชื่อรายการ/นิยามที่คล้ายกันไม่ถือว่ารวมกันได้ การตรวจสมการและ rounding เป็นหลักฐานประกอบ ไม่ใช้แก้ค่าต้นฉบับ

สถิติ DMF ที่ฐานเวลายังไม่ยืนยันเก็บใน contextual research database พร้อมข้อจำกัด ไม่ย้ายเข้า subset ของรายงานที่ยืนยัน annual basis นี้เพื่อเพิ่มยอด

## ขอบเขตที่ยังไม่อ้าง

- ACCEPTED_REFERENCE ไม่เท่ากับ NORMALIZED_LCI_EXCHANGE และไม่ใช่การอนุมัติโดยเจ้าของข้อมูลหรือกรรมการ
- จำนวน source observations รวม totals, components และ intensity ไม่ใช่จำนวน flows อิสระ ห้ามรวมทุกแถวเป็นยอดเดียว
- ค่าที่แปลงตัวคูณหน่วยใช้ชื่อ scaled_amount ไม่เรียก normalized LCI amount
- หน่วย m3/year รักษาไว้ตามต้นฉบับ ไม่ทำให้เท่ากับ m3 โดยตัดเวลาออก
- ประเทศไทยเป็นความเกี่ยวข้องของแหล่งและการดำเนินงาน ไม่อ้างว่าทุกตัวเลขเป็นค่าเฉลี่ยระดับประเทศ

## สิทธิใช้และการแจกจ่าย

แยก rights_status จาก data_quality_status ข้อมูลจากรายงานบริษัทเก็บสถานะ PUBLIC_REPORT_REUSE_NOT_CONFIRMED และ redistribution_status=NOT_CLEARED โดยตรง การรับเข้าชุดอ้างอิงภายในไม่ใช่การให้ใบอนุญาตใหม่แก่ผู้ใช้ปลายทาง ไม่แนบ raw PDF หรือไฟล์ lecture ในแพ็กเกจ export

ทุก export มี usage-profile และข้อจำกัด ผู้ใช้ต้องพิจารณาสิทธิของแหล่งก่อนเผยแพร่หรือใช้ในรูปแบบอื่น ทีมสามารถส่งโค้ด metadata และวิธีสร้างซ้ำได้โดยไม่ต้องอ้างว่าได้รับ open-data license สำหรับรายงานบริษัท

## ตรวจและทำซ้ำ

บันทึก actor เป็น AUTOMATED_TEAM_POLICY_V1 และระบุว่า AI-assisted ไม่สร้างชื่อผู้ตรวจที่เป็นสมาชิกขึ้นเอง ตรวจเลขจากการสกัดซ้ำทุก observation ใน subset, ตรวจ Decimal/metadata หลังเข้า MySQL และบันทึกเหตุ hold รายแถว

ผู้ใช้เปลี่ยนขอบเขตนโยบายได้ผ่าน version ใหม่ โดยคง snapshot/rule version เก่าไว้เพื่อให้ reproduce ผลเดิมได้
