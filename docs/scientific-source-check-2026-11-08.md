# ค้นหลักฐานเพื่อปิด LCI เพิ่มก่อนส่งต่อ — 8 พฤศจิกายน 2569

ตรวจแหล่งปฐมภูมิแบบเจาะจงเรื่อง allocation workbook และข้อมูลเดินระบบ TSM เพิ่มจากการทบทวนเดิม ผลยังไม่เพียงพอปิด gate; ไม่มีการนำเข้า numeric inventory เพิ่ม เปลี่ยนค่าต้นฉบับ ใช้ factor หรือคำนวณ CO₂e รวม

## Allocation และตัวตนรายงาน ARDA

- [ทะเบียน NRCT 3152](https://explore.nrct.go.th/search_detail/result/3152) ระบุโครงการด้านการจัดการปาล์มน้ำมันอย่างยั่งยืน ผู้วิจัยเสกสรร พาป้อง และปีเผยแพร่ 2560 ข้อมูลหน้าเว็บที่ตรวจยังไม่แสดง calculation workbook หรือหลักฐานว่าคือรายงานอ้างอิง 18 ใน Permpool et al. 2020 จึงคงเป็น candidate ที่ identity ยังไม่ยืนยัน ไม่ใช้ปีที่ตรงกันแทนหลักฐานความเป็นเอกสารเดียวกัน
- [จดหมายข่าว JGSEE ฉบับ 39 มกราคม–เมษายน 2021 หน้า PDF 4](https://www.jgsee.kmutt.ac.th/v3/wp-content/uploads/2019/08/JGSEE-Newsletters-vol.39-Jan-Apr-2021.pdf) ระบุทุน ARDA ปี 2021 สำหรับโครงการห่วงโซ่ปาล์มและโรงกลั่น **Phase II** ของทีม Gheewala เป็นช่องทางสืบต่อเรื่องหน่วยงาน/รุ่นโครงการ แต่เอกสารนี้เป็นข่าวทุน ไม่ใช่รายงาน 2017 หรือ workbook ฐาน Table 4 จึงไม่ใช้ปิดการปันส่วนหรือแทนปีวัด
- [หน้า MDPI ของบทความเดิม](https://www.mdpi.com/2071-1050/12/22/9415) เปิดตรงผ่าน web tool ได้ 429 รอบนี้มีข้อความจากดัชนีค้นของผู้เผยแพร่ แต่ไม่ใช้ snippet เพิ่ม observation หรือปิด table-specific allocation ใช้ทะเบียนการตัดสินเดิมใน `docs/fame-gate-closure-review.md` ต่อ

สิ่งที่ยังต้องได้คือคำอธิบายว่าปริมาณในแต่ละตารางเป็นก่อน/หลัง allocation และ treatment ของ co-products/upstream พร้อม locator/รุ่นเอกสาร การมีสัดส่วน 70/30 อยู่แล้วไม่ใช่เหตุให้คูณซ้ำ

## TSM: แยกหน้าโครงการกับผลเดินระบบ และแยกนิติบุคคล

- [หน้า validation ของ UNFCCC](https://cdm.unfccc.int/Projects/Validation/DB/8CIS1C5D9HBBRSIRR1R0STCX9SKQZC/view.html) ระบุว่ายอดลดรายปีเป็นการประมาณจาก PDD ที่ยังไม่ผ่าน validation หน้านี้จึงไม่ใช่รายงานมวล CH₄ ที่วัดหรือผลออกเครดิตจริง การตรวจรอบนี้ไม่ได้พิสูจน์ว่าไม่มี monitoring report อยู่ที่อื่น
- [หน้าธุรกิจพลังงานภาษาไทยของผู้ประกอบการ](https://tsmgroup.co.th/about-us/affiliated-company/energy-business/) แยก TSM Bio Energy กับ TSM Bio Energy (2012), ระบุขนาดกำลังผลิต 2 และ 4 MW และการใช้/ส่งต่อก๊าซชีวภาพระหว่างกิจการ ข้อมูลนี้ช่วยกำหนดว่าต้องตรวจ entity และ flow ข้ามโรงงานก่อนจับคู่ ไม่ใช่ปริมาณผลิตไฟฟ้าหรือมวลก๊าซจริงรายงวด ไม่รวมกำลังผลิตเป็นผลเดินระบบ และไม่แทนข้อมูลประวัติใน World Bank

ยังไม่พบคู่ข้อมูล **มวล CH₄ ที่ปล่อย/กู้คืนกับยอดผลิตเอทานอลจริงในงวดเดียวกัน** จากเอกสารที่ตรวจรอบนี้ จึงคงค่าความเข้มและ lifecycle total เป็น null ไม่ใช้กำลังผลิตรายวันหรือ MW แทนยอดจริง

## หลักฐานและขอบเขต

`evidence/scientific-source-check-2026-11-08.json` เก็บ URL/locator/ผลตัดสิน มีเฉพาะ metadata และข้อจำกัด ไม่ได้เก็บหรือแจก raw PDF/หน้าเว็บ ไม่อ้าง local PDF hash หรือ visual audit ของแหล่งปฐมภูมิรอบนี้ การตรวจเป็น targeted search ไม่ใช่ systematic review หรือคำยืนยันว่าแหล่งข้อมูลนั้นไม่มีอยู่

ขั้นต่อไป: เจ้าของงานตรวจว่ามีรายงาน ARDA/calculation sheets หรือ operating logs จากผู้ให้ข้อมูลเดิมหรือไม่ พร้อมสิทธิใช้ รุ่น งวด และ entity ที่ตรงกัน; หากมี public primary source ใหม่ค่อยตรวจเพิ่ม ไม่วนเรียก URL ที่ติดข้อจำกัดหรือสร้าง surrogate เพื่อให้ gate ผ่าน
