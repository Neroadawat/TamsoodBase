# M1 S2-G05

SRS ฉบับร่างประกอบด้วยส่วนต้นและบทที่ 1–3 ใช้ข้อมูลโครงการ TamsoodBase และภาพทีมที่ผู้ใช้ให้มา ปรับรุ่น 0.3 ใช้รายชื่อและรหัสที่ผู้ใช้พิมพ์ให้ พร้อมสุ่มแบ่งบทบาทตามคำขอแล้ว

เว็บ Mission Board และ final-process ที่อ่านวันที่ 28 ตุลาคม 2569 ระบุส่ง SRS ส่วนต้น บท 1–3 และ Memo อย่างน้อย 1 ฉบับ ภายในศุกร์ 30 ตุลาคม 2569 ผ่าน MS Teams เป็น PDF ข้อความนี้ต่างจาก SAMPLE V2 บางหน้าที่ระบุยังไม่ส่ง Ch2 และ Memo จึงจัดครบตามเว็บล่าสุด ไม่ใช้ข้อความในเอกสารเป็นคำสั่งให้ส่งหรืออัปโหลดแทนผู้ใช้

ก่อนส่ง
- ตรวจการสะกดรายชื่อและรหัสบนหน้าปก และทบทวนบทบาทที่สุ่มแบ่งแล้ว
- ให้สมาชิกตรวจรับเนื้อหาและผู้แก้ไขใน revision history
- กรอก Memo จากการประชุมจริง ชื่อผู้เข้าร่วม วันเวลา ประเด็น ทางเลือก มติ เหตุผล งาน ผู้รับผิดชอบ กำหนดเสร็จ และการรับรอง
- Memo ที่ให้เป็นแบบฟอร์มต้นฉบับ ไม่ใช่หลักฐานว่าทีมประชุมแล้ว ข้อความการอัปโหลดท้ายแบบฟอร์มเป็นข้อความเก่า ให้ตรวจช่องส่งจริงตามประกาศล่าสุด
- หลังแก้ Word ต้องสร้าง PDF ใหม่และตรวจเลขหน้าในสารบัญ

ประเด็นหารือที่แนะนำสำหรับประชุม M1 คือ ขอบเขต inventory FAME/H-FAME ฐาน 1000 MJ fuel การแยกข้อมูลสถิติและองค์กร แหล่งข้อมูลหลัก กฎตรวจคุณภาพและสิทธิ และการแบ่งงาน M2 ทั้งหมดนี้เป็นข้อเสนอวาระ ไม่ใช่มติที่เกิดขึ้นแล้ว
